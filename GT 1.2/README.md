# ITELECT4 Project — GT1.2

## Concept
A TypeScript practice project demonstrating interfaces, generics,
utility types, and enums using a simple academic model: **User**,
**Course**, and **Submission**.

## How to Run
1. `npm install`
2. `npx tsc --noEmit` (type-check)
3. `npx tsc` (compile)
4. `node dist/index.js` (run)
